# PROJECT VANTA — Bulut Oturumu Komutları

Her yeni bulut oturumunda aşağıdakilerden sıradakini kopyalayıp yapıştır.
Oturum bitince repoyu çek (`git pull`), `pnpm install` ve `pnpm dev` ile çalıştırıp dene, sonra bir sonrakine geç.

---

**Oturum 1 — M0**
```
Read CLAUDE.md. Complete Milestone M0 (Foundation) only. Create the pnpm monorepo layout, strict TypeScript, Vitest, a minimal Three.js client page and a minimal Colyseus server that both start with `pnpm dev`, plus the Docs files. Commit and report.
```

**Oturum 2 — M1**
```
Read CLAUDE.md and Docs/SessionLog.md. Complete Milestone M1 (Third-person core) only: greybox city block, capsule player, third-person camera with shoulder and zoom modes, action-map input, reusable interaction framework with one inspect example. Commit and report.
```

**Oturum 3 — M2**
```
Read CLAUDE.md and Docs/SessionLog.md. Complete Milestone M2 (Multiplayer) only: create/join room, 2–6 synced players with server-validated movement, reconnect window, and headless bots that can fill empty slots. Add a bot-based multiplayer test. Commit and report.
```

**Oturum 4 — M3 + M4**
```
Read CLAUDE.md and Docs/SessionLog.md. Complete M3 (random private professions, persistent character IDs) and M4 (VANTA picks IGL, one-way signal to IGL, IGL share UI per item and per teammate, replacement IGL on disconnect). Secrets must be filtered on the server. Add tests. Commit and report.
```

**Oturum 5 — M5**
```
Read CLAUDE.md and Docs/SessionLog.md. Complete M5: one Subject with photo, Citizen ID and approximate area, a server-side schedule moving between 3 locations, manual identification, and a simple "notices obvious surveillance" reaction that changes route. Commit and report.
```

**Oturum 6 — M6 + M7 başlangıcı**
```
Read CLAUDE.md and Docs/SessionLog.md. Complete M6 (data-driven case engine with unit tests) and start M7: a few evidence items, phone camera photos as evidence, and a shared case board UI. Commit and report.
```

**Kalan bütçe — First Playable'ı tamamla**
```
Read CLAUDE.md and Docs/SessionLog.md. Compare the project against the "First Playable" list. Implement the smallest missing pieces to make all 12 points work, including versioned save/load for case state. Commit and report.
```

---

**İpucu:** Bir oturum yarıda kalırsa yeni oturumda sadece şunu yaz:
```
Read CLAUDE.md and Docs/SessionLog.md. Continue the unfinished milestone from the last session. Commit and report.
```
